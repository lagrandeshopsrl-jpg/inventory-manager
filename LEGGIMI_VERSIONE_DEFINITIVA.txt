VERSIONE DEFINITIVA - Inventory Manager v60 Dropbox

Contenuto:
- v60 completa con sidebar/scanner
- sincronizzazione Dropbox reale tramite snapshot JSON
- collegamento account Dropbox tramite OAuth/PKCE
- niente dipendenza Supabase nella web app
- campo barcode che si svuota su click/touch/focus
- protezione anti upload database vuoto su nuovi dispositivi
- cronologia backup Dropbox: ogni upload crea un nuovo file con data e ora
- Fornitori, Categorie, Cronologia e Impostazioni operative
- rendering dati importati protetto da HTML/script inseriti nei campi

File principali da caricare nella root GitHub/Vercel:
- index.html
- app.js
- style.css

Uso:
- apri Impostazioni
- inserisci App Key Dropbox
- premi Collega Dropbox e autorizza l'account
- lascia il file predefinito /inventory_manager_snapshot.json oppure scegli un altro percorso
- lascia la cartella backup /inventory_manager_backups oppure scegli un'altra cartella
- premi Salva e poi Sincronizza

Importante:
- usa un token Dropbox revocabile
- per il collegamento diretto OAuth non aprire l'app da file://, usa Vercel/GitHub Pages/localhost e registra quel Redirect URI nella console Dropbox
- non caricare token dentro GitHub
- carica i file nella root del repository, non dentro una sottocartella
- dopo il commit su main aspetta il nuovo deployment automatico
